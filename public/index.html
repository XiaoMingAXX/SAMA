KNOW YOUR DEVICE

配置前，先知道这些

  • 默认：地址 2，9600 / 8 / N / 1。
  • 地址和通信参数使用 0x10 写多个寄存器，每次仅更改一个参数。
  • 波特率编码在手册中前后不一致。19200 示例使用 0x1920，本程序不推断其他档位的编码，请先向厂家确认。
  • 校验值：1 奇校验，2 偶校验；0 无校验由默认模式推定，需设备验证。
  • 传感器列出 9 位模式，但网关仅支持 7/8 位，因此此组合只开放 8 位。
  • 地址 0 的广播写入会影响所有从机，因此使用明确地址 1–247。
  • RS485 型号无需修改模拟量量程；手册没有提供 NPK 或 pH 校准寄存器。
FTX-W80 的 AT 指令来自附件手册。网络配置使用 HF UDP 48899 兼容通道，需实机确认；若不支持，请使用原厂配置网页或复制 AT 清单到厂家工具。

FROM HARDWARE TO INSIGHT

四步，开始观察。

电脑作为采集主机；同一局域网的设备通过浏览器访问。

01

接线与供电

传感器红线 → 电源正；黑线 → 电源负；黄线 → FTX-W80 A+/RX；绿线 → B-/TX。网关 + / − 接电源正 / 负。

土壤传感器
红 · V+黑 · GND黄 · A绿 · B
12 V 电源
FTX-W80

先断电接线。12 V 在两台设备供电范围内：传感器 3.3–24 V，网关 7–30 V。以实际线标为准。

02

连接 Wi-Fi 网关

电脑连接设备热点（手册名称有 HF-LPD30E / HF-LPDE 等差异，以实际为准），打开 10.10.100.254 ↗。串口设为 9600 / 8 / N / 1，网络设为 TCP SERVER、8899、透明传输。

账号手册有冲突：通用软件手册 admin/admin；使用说明 admin/damin。以设备标签或厂家确认为准。关闭额外心跳 / 注册包。

03

开始真实采集

到「设备配置 → 连接与采集」，选择真实设备。热点模式 IP 为 10.10.100.254；加入路由器后填写新的 IP。地址默认 2，选择你的型号支持的测量项。

pH 首次稳定需要超过 5 分钟。探针需充分接触土壤；含水率、温度等稳定时间通常少于 5 秒。

04

在局域网，一起使用

建议让网关以 STA/APSTA 加入路由器，电脑和手机连接同一路由器。手机打开「连接与采集」显示的电脑地址，例如 http://电脑IP:3000。

保持电脑运行且不休眠。若 Windows 提示网络访问，请允许专用网络；仅放行 TCP 3000，无需关闭防火墙。学校 Wi-Fi 可能启用客户端隔离，可使用独立路由器。

有读数，还要有判断

本系统展示原始测量结果，不预设「适合种植」阈值。盐分与 NPK 的单位来自手册示例；型号支持程度和测量准确性需要实机与校准验证。历史记录标注数据来源，不将模拟值混入真实设备档案。
